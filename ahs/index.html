KLAPUSTRI & Terme Grundlagen Optionales Fundament

Überspring das, wenn du dich schon sicher fühlst — sonst frische hier die 3 häufigsten Fehlerquellen auf.

Die 3 Grundregeln vor der Schularbeit:
  • KLAPUSTRI: Zuerst Klammer, dann Potenz, dann Punkt (·, :), zuletzt Strich (+, −).
  • Minusklammer: Steht ein Minus vor der Klammer, drehen sich alle Vorzeichen darin um: −(4x − 7) = −4x + 7.
  • Potenz eines Produkts: Jeder Faktor wird quadriert: (3a)² = 3² · a² = 9a² (häufiger Fehler: 3a²!).

Binomische Formeln & Höhere Potenzen

Ausmultiplizieren, Rückwärts-Faktorisieren (auch mit a⁴ und a²) und geometrischer Beweis.

Die drei binomischen Formeln:
1. Formel: (a + b)² = a² + 2ab + b²
2. Formel: (a − b)² = a² − 2ab + b²
3. Formel: (a + b)(a − b) = a² − b²
Tipp für höhere Potenzen: Bei 9a⁴ − 12a² + 4 steckt 3a² vorne und 2 hinten: (3a² − 2)².
Geometrischer Beweis

Warum darf man 2ab niemals vergessen?

Verändere die Seitenlängen a und b. Du siehst sofort, dass a² + b² nur zwei Ecken abdeckt — die beiden bunten Rechtecke a·b fehlen sonst!

Bruchterme & Definitionsmenge

Produkt-Nenner mit mehreren ausgeschlossenen Zahlen richtig bestimmen und Bruchterme vollständig kürzen.

Wann wird ein Bruchterm ungültig? (Produktsatz im Nenner)

Man darf niemals durch 0 dividieren. Steht im Nenner ein Produkt, etwa x · (x − 3), dann wird der Nenner 0, sobald mindestens ein Faktor 0 ist:

  1. Erster Faktor = 0 setzen: x = 0 → erster Ausschluss: x ≠ 0
  2. Zweiter Faktor = 0 setzen: x − 3 = 0 → zweiter Ausschluss: x ≠ 3
  3. Definitionsmenge: D = ℝ \ {0; 3}

Kürzungsregel: „Aus Differenzen und Summen kürzen nur die Dummen!“ Immer zuerst Zähler und Nenner faktorisieren (herausheben oder binomische Formel), erst dann gleiche Faktoren kürzen.

Schüler-Dolmetscher & Schularbeits-Checkliste

Was bedeuten die strengen Formulierungen auf dem Angabenzettel — und bist du bereit für die Arbeit?

Schüler-Dolmetscher: Angabe → Konkreter Rechenschritt

So steht es auf der Schularbeit Das heißt es übersetzt (Schritt für Schritt) Typisches Beispiel
„Vereinfache den Term so weit wie möglich.“ Klammern von innen nach außen auflösen, Potenzen ausrechnen und dann alle gleichen Buchstaben-Pakete (z. B. x² mit x²) zusammenzählen. 3x(x − 2) − x² = 2x² − 6x
„Zerlege in ein Produkt / Faktorisiere vollständig.“ Genau umgekehrt zum Ausmultiplizieren! Schritt 1: Gemeinsames herausheben. Schritt 2: Prüfen, ob eine binomische Formel passt. 9a⁴ − 12a² + 4 = (3a² − 2)²
„Bestimme die Definitionsmenge D.“ Schau nur auf den Nenner (unten). Setze jeden Faktor = 0. Alle Zahlen, die dabei herauskommen, sind verboten (≠). x(x − 3) ≠ 0 → x ≠ 0, x ≠ 3
„Kürze den Bruchterm vollständig.“ Niemals einzelne Glieder aus einer Summe streichen! Erst oben und unten faktorisieren, dann gleiche Klammern/Faktoren wegstreichen. (x² − 9)/(x + 3) = x − 3
„Berechne die fehlende Bestimmungsgröße.“ Skizze zeichnen, rechten Winkel markieren. Liegt die gesuchte Seite gegenüber vom 90°-Winkel? Dann plus (a² + b²). Sonst minus (c² − a²)! Kathete: b = √(c² − a²)
„Überprüfe, ob das Dreieck rechtwinklig ist.“ Die längste Seite allein quadrieren und vergleichen mit der Summe der anderen beiden Quadrate. Stimmt beides überein → rechtwinklig. 6² + 8² = 100 = 10² → Ja
